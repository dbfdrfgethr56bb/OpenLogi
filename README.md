## 🖱️ What Is OpenLogi?

OpenLogi is a powerful, privacy-focused replacement for Logitech Options+. It lets you take full control of your Logitech mouse—remapping buttons, adjusting DPI, and toggling SmartShift—all without creating an account, sending telemetry, or dealing with cloud services. Everything runs locally on your computer, so your data stays yours.

Think of it as a personal remote control for your mouse. You decide what each button does, how sensitive the sensor is, and how the scroll wheel behaves. No corporate oversight, no hidden tracking, just pure functionality.

## 🎯 How to Use OpenLogi

### Remapping Buttons

1. Open OpenLogi and select your mouse from the device list.
2. Click on the button you want to remap (left, right, middle, side buttons, etc.).
3. Choose a new function from the dropdown menu. Options include:
   - Standard actions (copy, paste, undo, etc.)
   - Media controls (play/pause, next/previous track)
   - System commands (volume up/down, screenshot)
   - Keyboard shortcuts (any combination)
   - Application launchers
4. Click "Apply" to save your changes.

### Adjusting DPI

1. Navigate to the "Sensitivity" tab.
2. Use the slider to set your preferred DPI (dots per inch). Lower values mean slower cursor movement; higher values mean faster.
3. You can set multiple DPI levels and switch between them using a dedicated button if your mouse supports it.

### Configuring SmartShift

1. Go to the "Scroll Wheel" section.
2. Toggle SmartShift on or off.
3. Adjust the threshold—how much force is needed to switch between free-spin and clicky modes.
4. Set the default mode when starting the computer.

## 🛠️ Troubleshooting Common Issues

### Mouse Not Detected

- Ensure your mouse is powered on and connected.
- Try reconnecting via a different USB port or Bluetooth pairing.
- Restart OpenLogi after reconnecting.

### Changes Not Taking Effect

- Check that you clicked "Apply" after making changes.
- Some settings require the mouse to be idle for a moment. Wait 2-3 seconds.
- Restart OpenLogi or your computer if issues persist.

### Application Won't Start

- Verify your system meets the minimum requirements.
- Temporarily disable antivirus software that might block the application.
- Download the file again to ensure it wasn't corrupted during transfer.
